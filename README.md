# Predicting the consequences of conformal screening decisions

Manuscript, supplementary information and all code for *"Predicting the consequences of conformal screening decisions: finite-sample audit intervals for batch outcomes"* (P. H. Zwart, in preparation for *Digital Discovery*).

A conformal classifier's two class-wise coverage requests serve as coordinates for navigating screening decisions. A labelled audit set, a random sample of the library to be screened, predicts how many confident hits, false leads, missed in-class candidates and measurements the next batch will contain. The predictions come with finite-sample intervals that hold with a specified probability under exchangeability alone, even after a setting is chosen. Teams or automated planners can then choose a setting under chance constraints on assays, budget or yield.

## Contents

| Path | What it holds |
|---|---|
| `main.tex`, `esi.tex`, `refs.bib` | Manuscript and electronic supplementary information (built PDFs alongside) |
| `figures/`, `tables/` | Every figure and table, generated by the scripts below; no hand-typed numbers |
| `code/` | Simulations: threshold correction, audit intervals, selection, ties, calibration-only intervals, cost analysis |
| `mol/` | Molecular and materials pipeline: Tox21, AqSolDB, CALiSol-23, scenario maps, per-plate bounds |
| `mol/v2/` | Stored results, including split indices and model scores, so every interval can be recomputed without refitting |
| `data/` | Raw inputs with `SHA256SUMS` |

`code/README.md` lists every script with the command that regenerates each table and figure and its runtime.

## Quick start

```bash
pip install -r code/requirements.txt          # Python 3.13
cd code && python3 -I validate_intervals.py 10000 validation.json   # Fig. 2
cd ../mol && python3 -I scenario_map.py v2/scenario_map.json ../figures   # Fig. 7 scenarios
latexmk -pdf esi.tex && latexmk -pdf main.tex  # ESI first: main.tex reads its labels
```
